# 视频提示词（分镜段落 → video_prompt）生产级规范

根据单个分镜段落的 description（含【镜头N】微动作与台词/旁白）/ atmosphere / duration / 镜头运镜 / 绑定的角色与道具，生成直接驱动高端 AI 视频大模型（如 MiniMax H3、Kling、Wanx 等）的工业级 `video_prompt`。

## 生产级四层结构（必须完整生成）

### 1. 任务与参考素材精确映射（正向采纳与负向排除 - 核心关键！）
首行明确任务与各参考图特征边界，明确“只采用什么、排除什么”，彻底根治多图混淆和背景乱串：
- `任务：参考@场景名 的环境布局、@角色名 的人物外观、@道具名 的物理造型，生成高品质连续镜头。`
- `场景：@场景名 对应场景参考图（只采用空间布局、家具陈设、光线氛围，不采用图中无关主体或背景杂物）。`
- `主体：@角色名 对应角色参考图（只采用五官面容、发型妆造、体型姿态、服装质感，不采用图中其他杂物或纯色背景）。`
- `道具/产品：@道具名 对应道具参考图（只采用轮廓外观、材质颜色、按键/结构细节，不采用图中的3D文字层或外包装）。`

### 2. 风格与视觉质感系统
- 真实感来源：自然光生活质感 / 电影胶片感 / 原生手机微手持，非棚拍假质感；
- 色彩与材质：低饱和暖色调、真实哑光材质、微弱高光、通透感；
- 动态光影事件：自然窗光方向、室内偏亮略过曝日常感；按键/动作时色温从冷白变暖橙。

### 3. 分秒镜头执行细节（按 3 秒一段，换行分隔）
每个时间段内必须包含：
- **时间范围与拍法运镜**：如「0-3秒：中近景手持微晃，从达人面部推近至墙面开关方向」、「3-6秒：固定中景轻微手持，光线变化时镜头光圈自然适应」、「6-9秒：近景特写微距推进，浅景深清晰对焦」；
- **微动作与身体反应因果**：动作可见具体动词与身体反应（手指滑动、按键瞬间肩膀明显下沉放松、靠回枕头、手指触摸边角）；
- **对白与唇形口播**：直接提取自 description 的台词，写为 `[角色名]（语气与语速说明）: "台词内容"`；
- **环境物理音效**：如按键“嗒”一声、轻微电流声、窗帘滑动声、轻拍触感；
- **光影与色温变化**：画面色温明显从冷白变为暖调柔光。

### 4. 全片连续性与负向硬约束（末尾必备）
- `全片保持主体、道具与场景连续一致；服装发型妆容全片不变；场景家具与空间布局不变；`
- **负向排斥硬约束**：`全片保持无字幕，不生成任何文字、字幕、标题、水印、标识或说明性文本。`

## 引用规则
- `@场景名` — 场景引用，名字必须与场景列表中的地点完全一致；
- `@角色名` — 角色引用，名字必须与角色列表中的名字完全一致；
- `@道具名` — 道具引用，名字必须与道具列表中的名字完全一致；道具在画面中明显可见、被使用或特写时引用；
- 生成时会自动把 `@名字` 替换为对应参考图片标记（如 `@小明` → `@图片1小明`，或由 MiniMax H3 自动转译为 `<Subject N> / [Image N]`）。

## 保存
调用 `update_storyboard` 仅更新该分镜段落的 `video_prompt` 字段，不要改动其他字段。
