# 分镜拆解工业级指南

## 核心定义：分镜段落

一个分镜 = 一个 **分镜段落**（segment）= 一个视频生成任务。

- 每个段落时长 **8-15 秒**，内部承载 **2-4 个子镜头**；
- 子镜头之间**可以切镜**：换景别、换角度、换拍摄对象，用硬切衔接；
- 子镜头之间**不跨场景**：一个段落只发生在一个场景内（`scene_id` 是段落级绑定）；
- 每个子镜头 2-6 秒，聚焦一个完整的画面单元（动作发起、互动因果、情绪反应或特写）。

## 拆分流程（四步）

1. 调用 `read_storyboard_context` 读取剧本、角色、场景、道具、已有分镜摘要；
2. **节拍识别**：先识别剧本的叙事节拍（开场建立、冲突触发、高潮反转、情绪收束）。**节拍边界强制切段**，同一节拍内的动作因果链（铺垫-发生-反应）不切散到不同段落；
3. **总量锚定**：目标总时长 = 剧本字数 ÷ 500字/分钟；段落数 ≈ 目标总时长 ÷ 12秒，允许 ±20% 浮动；
4. **段落内拆子镜头**：按动作切换点、视角切换点、对象切换点切分子镜头，为每个段落补全完整生产字段后调用 `save_storyboards` 一次性保存。

## 生产级镜头质量标准（必须深度吸收）

杜绝空泛抽象词，将一切转化为摄影机能拍到的物理细节、动态光影、微动作因果与三维声音设计：

### 1. 画面描述 `description` 细致度
按 `【镜头1】`、`【镜头2】`…逐子镜头描述观众实际看到的画面细节：
- **微动作与身体反应因果**：拒绝只有简单的“站着/看手机/走过去”，必须写出肢体细节与肌肉反应。例如：“靠在床头，手指在屏幕滑动，皱眉看了一眼刺眼的顶灯；伸手按下开关瞬间，肩膀肉眼可见地松弛下沉，整个人靠回枕头”。
- **动态光影与视觉事件**：写明环境光源变化。例如：“窗帘缓缓拉上，顶灯暗下，暖橙色氛围灯微光亮起，房间色温从冷白迅速过渡为暖调柔光”。
- **道具与产品露出**：写明尺寸、质感、位置与互动方式。例如：“米白色云朵造型开关贴在床头伸手可及处，表面哑光质感，手指按下正面圆形按键”。
- **台词与对白**：标明说话人情绪状态与语速。以「角色名说：「台词」」写在对应【镜头N】内，旁白写「旁白：内容」。

### 2. 镜头语言与运镜（`shot_type`, `angle`, `movement`）
- `shot_type`：写明主导景别与景别组合（如“中近景+近景特写”、“微距特写”）；
- `angle`：平视、微俯、微仰、过肩视角等；
- `movement`：具体的摄影机运动与光学反应。例如：“手持微晃，从达人面部推近至开关”、“固定中景轻微手持，光线变化时镜头光圈自然适应”、“微距近景特写推进，浅景深虚化背景”。

### 3. 光影氛围（`atmosphere`）
具体描写光源性质、方向、色调与动态变化。例如：“暖色自然光从右侧窗户打入，室内偏亮略过曝的日常感；按键后光线从偏亮迅速过渡到暖调柔光，床头暖橙氛围灯微光”。

### 4. 声音系统（`sound_effect` 与 `bgm_prompt`）
- `sound_effect`：具体的物理互动音效。例如：“轻微手机滑动声、手指按键'嗒'一声清脆触感、灯光切换低沉嗡鸣、窗帘轨道轻微滑动声”；
- `bgm_prompt`：专业音乐配器与动态曲线。例如：“lo-fi 慢拍 chill 风格，约 80 BPM 轻柔四拍鼓点配温暖钢琴单音铺底，光线切换时鼓点轻轻进入，尾音渐弱”。

### 5. 视频生成提示词（`video_prompt`）生产级结构
1. **首行写明任务与参考图正向采纳/负向排除边界**（如：场景：@场景名 对应场景图，只采用空间布局陈设与光线，不采用杂物；主体：@角色名 对应角色图，只采用五官发型服装姿态，不采用纯色背景；道具：@道具名 对应道具图，只采用外观轮廓按键布局，不采用3D字层）；
2. **按 3 秒为一段换行**，每段写明时间范围 + 拍法运镜 + 画面与微动作因果 + 露出交互 + 对白口播 + 光影色温变化；
3. **尾部硬约束声明**：全片保持主体、产品与场景连续一致；服装发型妆容全片不变；全片保持无字幕，不生成任何文字、字幕、标题、标识或说明性文本。

## 台词时长下限（硬规则）
**段落时长 ≥ 段内台词与旁白总字数 ÷ 4.5字/秒 + 2秒表演余量**，装不下的台词必须拆到下一个段落。
